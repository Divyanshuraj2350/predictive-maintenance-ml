# ⚙️ Predictive Maintenance ML System

## 📌 Overview
This project is a Machine Learning-based Predictive Maintenance system that predicts whether industrial equipment will fail based on sensor data.

It uses a trained Random Forest model and provides real-time predictions through an interactive web application.

---

## 🚀 Features
- Predict machine failure using sensor inputs
- Display failure probability
- Interactive Streamlit web app
- Feature importance visualization
- Deployed online using Streamlit Cloud

---

## 🧠 Machine Learning Model
- Algorithm: Random Forest Classifier
- Dataset: AI4I Predictive Maintenance Dataset
- Accuracy: ~99%

---

## 📊 Input Features
- Machine Type
- Air Temperature
- Process Temperature
- Rotational Speed
- Torque
- Tool Wear
